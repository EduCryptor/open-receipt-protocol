# Contributing

You do not need to be a programmer to contribute.

| Contribution | Example |
|---|---|
| Explain a confusing passage | “I could not tell whether the token stores an email address.” |
| Describe a checkout failure | “This supermarket scanner cannot read customer QR codes.” |
| Review privacy risks | “A permanent token could let stores correlate purchases.” |
| Improve the prototype | Add a clear delivery-failure state. |
| Propose a protocol change | Explain the problem, proposed behavior, and tradeoffs. |

For substantial changes, open a GitHub issue before writing code. Keep each pull request focused on one problem.

Never submit real receipts, payment credentials, personal email addresses, or customer data to this repository.
